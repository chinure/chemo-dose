# 化疗药物剂量计算 H5

这是用于公众号菜单跳转的静态 H5 版本，不依赖后端、数据库或构建工具。

## 本地预览

在本目录运行：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://127.0.0.1:8080/
```

## 部署

将本目录下文件上传到任意 HTTPS 静态网站空间：

- `index.html`
- `styles.css`
- `app.js`
- `manifest.json`

部署后得到类似下面的网址：

```text
https://example.com/chemo-dose/
```

在微信公众号后台配置菜单时，将菜单类型设为“跳转网页”，URL 填这个 HTTPS 地址。

## 公众号菜单配置

推荐路径：

1. 登录微信公众平台：`https://mp.weixin.qq.com/`
2. 进入公众号后台的自定义菜单配置页面
3. 新增菜单，例如：`剂量计算`
4. 菜单内容选择：`跳转网页`
5. 网页地址填写部署后的 HTTPS 地址，例如：

```text
https://example.com/chemo-dose/
```

6. 保存并发布菜单

## 减少备案麻烦的部署建议

优先使用已有备案和 HTTPS 的网站域名，例如医院官网、科室已有网站或单位服务器的子目录：

```text
https://www.example-hospital.com/tools/chemo-dose/
```

如果新买国内服务器和新域名，通常仍可能涉及网站 ICP 备案。这个方案能避开“小程序备案、审核、发布”，但不能保证避开所有网站域名备案要求。

如果只是内部少量试用，可以先部署到已有内网服务器或临时静态托管地址，确认手机端体验后再决定正式域名。
